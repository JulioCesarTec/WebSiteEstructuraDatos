Introducción

¿Qué son los métodos de búsqueda?

Son algoritmos que permiten encontrar un dato específico dentro de una estructura, como un arreglo, una lista o una tabla. La elección depende de cómo están organizados los datos y de la rapidez que se necesita.

01

Búsqueda secuencial

Revisa los elementos uno por uno hasta encontrar el valor o llegar al final.

02

Búsqueda binaria

Divide el intervalo de búsqueda a la mitad. Requiere datos ordenados.

03

Búsqueda por HASH

Calcula una posición mediante una función hash para acceder a los datos.

Tema 6.1

Búsqueda secuencial

También llamada búsqueda lineal. Es uno de los métodos más sencillos y puede utilizarse aunque los datos no estén ordenados.

¿Cómo funciona?

Comienza en el primer elemento y compara cada valor con el dato buscado. Si coinciden, devuelve la posición. Si llega al final sin encontrarlo, informa que el elemento no existe.

Características

  • No requiere que los datos estén ordenados.
  • Es fácil de implementar y comprender.
  • Puede detenerse al encontrar la primera coincidencia.
  • En el peor caso revisa todos los elementos.
Complejidad: O(n) en el peor caso, porque puede revisar todos los elementos.

Ejemplo cotidiano

Buscar un nombre en una lista desordenada, leyendo desde el principio hasta encontrarlo.

Tema 6.2

Búsqueda binaria

Es un método eficiente para colecciones ordenadas. En cada paso descarta aproximadamente la mitad de los elementos que todavía podrían contener el valor.

¿Cómo funciona?

Se identifican los límites inferior y superior del arreglo y se calcula la posición central.

  • Si el valor central es igual al objetivo, se encontró.
  • Si el objetivo es menor, se continúa en la mitad izquierda.
  • Si es mayor, se continúa en la mitad derecha.
  • Termina cuando se encuentra el dato o el intervalo queda vacío.
Requisito: los datos deben estar ordenados. Complejidad: O(log n) en el peor caso.

Ejemplo cotidiano

Buscar una palabra en un diccionario: se abre cerca de la mitad y se decide qué parte revisar según el orden alfabético.

Tema 6.3

Búsqueda por funciones de HASH

Utiliza una función matemática para transformar una clave en un índice de una tabla hash y acceder al lugar donde se almacena el dato.

¿Cómo funciona?

Una función hash recibe una clave y calcula una posición dentro de una tabla. Una función sencilla para claves numéricas es:

h(clave) = clave módulo tamaño_de_tabla
El operador módulo (%) obtiene el residuo de una división.
  • Se calcula el índice aplicando la función hash.
  • Se consulta la posición correspondiente.
  • Si hay más de una clave en el mismo índice, se debe resolver la colisión.

Colisiones

Ocurren cuando dos claves diferentes producen el mismo índice. Una solución es el encadenamiento: guardar una lista de elementos en cada posición que comparte índice.

Complejidad: O(1) promedio con una buena distribución; O(n) en el peor caso si muchas claves colisionan.

Ejemplo cotidiano

Un inventario puede calcular una posición a partir del código numérico de cada producto para acceder a su registro.

Análisis comparativo

Comparación de los métodos

La complejidad permite estimar cómo cambia el trabajo del algoritmo cuando aumenta la cantidad de datos.

Método¿Requiere orden?PromedioPeor casoUso recomendado
SecuencialNoO(n)O(n)Datos pequeños o desordenados.
BinariaSíO(log n)O(log n)Datos ordenados y acceso por índice.
HASHNoO(1) esperadoO(n)Consultas frecuentes por clave.
Conclusión: no existe un único método ideal para todos los casos. La búsqueda secuencial destaca por su sencillez, la binaria por su eficiencia en datos ordenados y HASH por su acceso promedio rápido mediante claves.
